# Simple Python Calculator 🧮

A lightweight, interactive command-line calculator written in Python that performs basic arithmetic operations.

## 🚀 Features
* Supports Addition, Subtraction, Multiplication, and Division.
* **Error Handling:** Includes a built-in safety check to prevent program crashes when dividing by zero (`n2 == 0`).
* Built using clean, conditional control flow logic (`if/elif`).

## 🛠️ How to Run
1. Make sure you have Python installed.
2. Run the file in your terminal:
```bash
   calculate.py
